设置 主卡片		日常只看「已连接 · 在线」状态点；安装 ID、断开按钮收进设置主卡片。
拨打电话（模块选择 + 号码 + 拨打）拨号模块 Picker 变成号码下方的「线路」胶囊；号码输入改为键盘输入 + 粘贴/删除；不支持主动拨号时呼叫键置灰并提示。
当前通话（接听/拒接/静音/扬声器/DTMF/挂断/计时）来电 / 通话中 全屏页来电：大头像 + 绿接红拒；通话中：静音/键盘(DTMF)/扬声器/添加通话/视频/联系人六键 + 挂断。通话属沉浸式场景，从任一页来电即覆盖全屏。
通话记录（方向/模块/结果/时长/清除）通话记录按天分组；方向用色标图标（绿=呼出、紫=呼入、红=未接、橙=未接通）；模块显示为标签；每行带绿色回拨键；清除按钮保留二次确认。
配对与接听（扫码/导入/连接断开）设置 配对与设备扫码、导入 JSON 配对文件各一行；连接/断开提升到主卡片。
后台来电（状态 + 开关）设置 通话改为标准开关行，状态文案作为副标题。
恢复配对（指纹/清理凭据）设置 配对与设备指纹行支持一键复制；清理凭据为红色警示行，保留确认弹窗文案。
本次联调诊断设置 数据与支持折叠为「联调诊断」入口行，点入查看等宽日志。
—（新增）联系人原版无联系人功能。建议本机实现：常用联系人（家人快捷头像）+ 全量列表，数据可由通话记录聚合 + 手动收藏，仅保存在本机，与「通话记录仅存本机」的隐私口径一致。
