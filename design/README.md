# DJOneHub Phone · 界面重设计（「暖阳」方向）

> 仅设计稿，不涉及任何代码改动。打开 `index.html` 查看总览画廊与设计规范；每个页面均可单独在浏览器中打开预览。

## 设计目标

把原先拥挤的单页 Form（`ios/DJOneHubPhone/Sources/PhoneApp.swift`）拆成 **拨号、联系人、通话记录、设置** 四个独立页面，风格为 **柔和渐变色 + 圆润元素**——更有亲和力和温度，面向家庭用户的消费级产品。

## 文件清单

| 文件 | 内容 |
| --- | --- |
| `index.html` | 总览：六屏画廊 + 功能迁移对照表 + 设计规范 |
| `dialer.html` | 拨号页（键盘 / 线路选择 / 呼叫） |
| `contacts.html` | 联系人页（常用联系人 + 全量列表，新增页面） |
| `recents.html` | 通话记录页（按天分组 / 方向色标 / 回拨） |
| `settings.html` | 设置页（连接卡片 / 配对 / 后台来电 / 数据） |
| `incoming.html` | 来电全屏页（接听 / 拒接） |
| `call.html` | 通话中全屏页（静音 / DTMF 键盘 / 扬声器 / 挂断 / 计时） |
| `assets/style.css` | 共享设计系统（色板、圆角、阴影、组件） |

## 视觉语言

- **背景**：蜜桃 → 粉樱 → 薰衣草三段柔和渐变（`#FFEAD3 → #FFD9E3 → #E3D7FB`），各页面统一
- **表面**：奶油玻璃拟态（白色 72% + 背景模糊），紫调柔和投影
- **圆角**：拨号键 24 / 卡片 28 / 列表行 20 / 按钮全圆角
- **主 CTA**：珊瑚橙渐变（`#FF9A5A → #FF5C74`），仅用于「呼叫」这一最关键动作
- **状态语义色**：绿＝在线/呼出/接听，紫＝品牌/呼入，红＝未接/挂断/危险，橙＝未接通
- **字体**：SF Pro Rounded / PingFang SC，粗字重、大号码

## 功能映射要点

- **拨号**：连接状态缩为顶部胶囊（绿点=在线）；模块 Picker 变成号码下方的「线路」胶囊；`dialingSupported == false` 时呼叫键置灰并提示「当前服务仅支持接听」
- **联系人**：原版没有联系人功能，建议本机实现——常用联系人（家人头像快捷拨打）+ 全量列表，数据由通话记录聚合 + 手动收藏，仅保存在本机（与现有「通话记录仅保存在此 iPhone」口径一致）
- **通话记录**：方向箭头改色标图标，模块（`entry.module`）显示为标签，结果与时长合并为一行说明，保留「清除已结束记录」及二次确认
- **设置**：连接状态升为渐变主卡片（在线状态、安装 ID、断开连接）；扫码配对 / 导入配对文件 / 公钥指纹（可复制）/ 清理本机凭据归入「配对与设备」；后台来电改为开关行；联调诊断折叠为入口行
- **通话**：来电与通话中独立为全屏沉浸页（不占标签栏），接听绿 / 拒接挂断红；通话中六键控制含 DTMF 键盘入口，与 `runtime.callControlsSupported` / `dtmfPending` 状态对应

## 后续落地建议

- SwiftUI 侧可用 `TabView` 承载四个主页面，通话状态用 `fullScreenCover` 呈现
- 渐变背景抽成 `AppBackground` 视图修饰符；键盘、卡片、列表行做成可复用组件
- 色板建议落在 `Assets.xcassets` 的 Color Set，支持深浅色（本稿为浅色方向）
