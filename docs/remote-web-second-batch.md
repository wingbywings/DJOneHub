# Web 配对第二批实施记录

2026-10-13，分支 `codex/remote-iphone-callkit`。承接用户确认的[Web 配对方案](REMOTE_WEB_PAIRING_PLAN.md)，继续 W03/W04 与发行入口迁移。未操作真实 Keychain、APNs 文件或现有 Mac/公网服务。

## 已实现

- 在现有 Mac Web 服务增加 `/remote/`，通过主导航进入；注册、授权导入、profile/连接、手机 QR、邀请、安装与模块目标集中管理。
- 启动器通过鉴权的原生通道取得独立两分钟一次性票据，系统 API 打开 URL，票据不进入 argv/日志；页面立即清除 fragment，建立本机管理 session。可设置管理密码，过期可通过启动器重新登录。
- 钥匙串/网络操作为串行后台任务，GET 状态只读取公开元数据索引；支持刷新后查询运行中的任务。任务不随发起 HTTP 请求断开而取消，凭据结果不确定时不自动消费旧授权。
- 申请候选仅取实际可用设备；服务端重新校验 ID。导入授权预览申请/服务器/指纹/模块/期限，后端与持久化密钥匹配。旧 profile 读取后加入非敏感 SQLite 索引，不重新登记。
- 动态连接保存重启选择；普通启动器 start 接入 native control 与 AudioHost。切换先冻结稳定设备集合的通话路由，原子退出空闲 Manager，待旧连接关闭后再发布新 Manager。新 Manager 发布前不建立 WSS；活动调用、清理或 journal 恢复拒绝切换。
- 手机只选择本机已知且 Hub 已授权模块。原生 CoreImage 生成 PNG，配对文件格式与现有 iPhone App 兼容。五分钟一次性 secret 仅在受鉴权的短时任务结果交付，不写索引；到期或确认消费后清除服务器临时交付内容。
- 按 grant 查询精确登记的安装身份，支持历史邀请列表及撤销；读取/备注/撤销手机，撤销前预览本机引用和通话。推送登记与当前在线区分，未知时间不造数据。
- 原 Web 安装 ID 输入替换为手机下拉；模块目标保存再次验证当前 Hub、未撤销及模块范围。失效旧目标保留并标明，不自动改为另一部手机；AI 配置保持原值，启用 AI 时远程路由不触发。
- 配对后批量应用先预览 AI/模块状态，逐项保存、逐项报告。没有跨模块原子事务承诺。
- 独立 Mac 配对窗口迁出主要发行包，remote-ui 成为 Web 兼容入口，CLI 保留。旧路由脚本在新鉴权边界下先停止，不会先关闭 AI 再发现远程保存失败。

## 验证与边界

Go 定向竞态与临时 HTTPS/SQLite 集成通过：完整创建/提交/批准/绑定消费、模块同名正确 ID、跨 Hub/模块拒绝、已撤销目标拒绝、邀请精确结果与 secret 清除、活动/恢复门控、只读状态不访问 Vault、并发任务拒绝重复、CSRF/Host/Origin/旧 PUT 绕过拒绝。真实临时 TLS/WSS 验证了发布前不连接、发布后鉴权 online 和空闲退出。状态 API 与快速切换的锁顺序竞态、原生 QR PNG、票据一次性/过期/会话/权限边界测试通过。

主页面 JavaScript 验证了异步切模块后旧读/旧保存失败不会覆盖新模块，按授权过滤手机、非法目标不发送保存、未登录不可编辑；两份脚本语法与 shell 语法通过。全仓库 `go test -race -tags remoteopus ./...` 通过。

已生成 `dist/release/DJOneHub-macOS-arm64-web-pairing-20261013.zip` 与 SHA-256 文件。Hub/AudioHost 签名验证、依赖检查、ZIP 内容/校验和通过；实际发行二进制在隔离 demo 模式核对了静态 Opus 1.6.1 和嵌入 Web 资源。包中保留新旧版本操作指南及 Relay 管理部署说明，未包含独立配对窗口或个人凭据。Relay 源码升级包也已重新生成，纳入本批管理接口和文档。

本批提交时浏览器点击验收受锁屏阻塞。后续用户解锁后已完成临时身份的双 Web 注册与配对管理验收，详见[浏览器验收记录](remote-web-browser-acceptance.md)。真实旧 profile 导入、新版安装、扫码及前台/锁屏双向电话仍待实际环境验收。Keychain 的系统授权不能由网页代为确认；任务超时不能当作消费失败。
