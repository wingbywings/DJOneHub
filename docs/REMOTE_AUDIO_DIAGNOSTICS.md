# iPhone 单向无声诊断

2026-10-10：用户确认 APNs 和后台接听可用，但 iPhone 听不到对方，
对方能听见 iPhone。前台接听也出现，切换扬声器后仍无声。
已定位并修复服务端收发音频的时钟累积漂移；2026-10-10 用户真机复测确认“已恢复”。

## 复现证据与修复

真实通话 `b7da81a6-e994-4915-a567-c978e1c192b9` 结束后的统计：

- 下行采集 2,682 帧，有信号 173 帧，峰值 20,080；丢弃 608 帧，编码 1,034 包。
- 上行解码仅 24 包，拒收 1,289 包，随后产生 128,240 个静音样本。
- iPhone 每 5 秒仅收到约 190–195 包；已启用接收轨道和音频，解码能量曾增长。
  说明至少部分下行已到达并解码，不是完全无 PCM 或完全无下行 RTP。

`Sender.Next` 和 `Receiver.Read` 原先每次以 `now + period` 重设期限。
定时器相位存在微小抖动，下一次 tick 略早于期限便跳过整次处理，
而下一次处理又从延迟后的时间重设期限，造成持续降速。
确定性测试仅加入微秒抖动，就将 5 秒编码包数降至 167、丢弃 162 帧；
接收端第 38 个 tick 开始将合法输入判定为超出 200 ms 窗口。

修复为沿既定媒体时钟递增期限。发送端遇到真正停顿仍重新计时，不突发补发旧音频；
接收端保留原有停顿检测和重新缓冲逻辑。新增长时间抖动回归测试，并验证
状态统计在并发运行及挂断后读取时仍正确。

修复后通话 `a1ebed33-3b60-41fa-b18a-c5531837d1d8`：下行采集 1,324 帧、
编码 661 包、丢弃 0 帧；上行解码 417 包，`RejectedPackets=0`。
用户确认声音恢复；通话正常远程挂断、清理成功，Hub 恢复在线。
仍记录上行 `LatePackets=219` 和 36,320 个静音样本，说明上行固定 60 ms
缓冲的弱网适应能力仍有改进空间；不能将本次修复解释为所有网络丢包/迟到均已解决。

## 已准备的诊断

- Hub 的 `GET /api/devices/<module_id>/remote-calls/status` 在 `session.media`
  中增加 `audio_active`、`downlink`（模块到 iPhone）、`uplink`（iPhone 到模块）。
- `downlink.CapturedFrames` 是通过音频门控后收到的 10 ms PCM 帧数；
  `SignalFrames` 是峰值至少为 128 的帧数；`PeakPCM16` 是本次采集的最大绝对幅值；
  `EncodedPackets` 是编码成功的 20 ms Opus 包数。
  `DroppedFrames`/`QueuedFrames` 帮助识别采集积压或时间戳断档。
- `uplink.Packets`/`DecodedPackets` 记录手机上行接收、解码数量。
- App 设置页“本次联调诊断”每 5 秒追加 `audio_rx` 和 `audio_play`。
  前者记录下行 RTP 包数、字节数、样本数、隐藏丢包样本数与累计音频能量；
  后者记录音频门控、接收轨道数、已启用轨道数、输出端口类型与输出音量。
- Hub 累计计数在挂断后保留至下一次会话替换；App 停止统计任务，保留最近 24 条诊断。
  不记录音频内容、完整 WebRTC 统计、候选地址、SDP 或凭据。

## 复现与判读

1. 用诊断版接听真实来电，让对方连续说话至少 15 秒，然后挂断。
2. 保存 App 的 `audio_rx`、`audio_play` 行及相同通话的 Hub `session.media`。
3. 对照以下边界继续排查，累计峰值不能证明整个通话持续有声：

| 观测 | 下一步 |
| --- | --- |
| 通话期间 `audio_active=false` | 检查 CallKit、模块、Host 就绪与门控状态；挂断后的 false 正常 |
| `CapturedFrames=0` | 检查 UAC 采集、本机 WebSocket 与门控；连接成功本身不能证明有 PCM |
| 采集帧增长，但对方说话时 `SignalFrames=0` | 检查模块下行路由及 UAC 输入，当前送入编码器的音频近乎静音 |
| 采集有信号但 `EncodedPackets` 不增长 | 检查帧时间戳、队列丢弃、编码及会话错误 |
| 服务端编码增长，手机 `packets=0` | 检查 RTP 发送、协商和 TURN 下行路径 |
| 手机包数增长，但能量为零 | 结合 samples/concealed、源 PCM 和音频门控检查解码/播放；缺少可选统计字段也显示零 |
| 手机能量增长，但仍听不见 | 检查音频轨道、AVAudioSession 输出、系统音量及真机播放 |
