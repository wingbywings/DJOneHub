# Web 配对首批实施记录

日期：2026-10-13；分支：`codex/remote-iphone-callkit`。依据用户已确认的[实施方案](REMOTE_WEB_PAIRING_PLAN.md)。

本批落地身份/授权基础和独立 Relay 管理页面。没有替换现有 Mac、AudioHost、iPhone 或公网 Relay，没有读取真实 APNs 私钥。全流程 Web 迁移仍在实施中。

## 已实现

- identity schema 1/2 可事务迁移到 3，保留已有身份/凭据；旧记录未知的创建时间保持未知。
- Mac 签名申请先持久化 Keychain 密钥再提交。审批限定申请模块或其子集，授权文件绑定申请及公钥，最长十分钟；重签发、撤销和并发消费不会重复登记。
- 原生 Relay 增加受限申请提交，以及 Hub 鉴权的手机/邀请管理接口；原有浏览器 Origin 禁止策略保持。公开申请受原有 IP/全局限流、16 KiB 文件、256 个有效申请及单公钥三个有效申请限制。
- 独立 `djonehub-relay-admin` 监听回环 18444，通过独立 HTTPS 站点反代。登录、初始化、Cookie/CSRF、精确 Origin/Host、私有账户文件和审计库已接入；长期身份凭据不交给浏览器。
- 管理页面支持导入申请、按候选模块勾选批准、签发/重新签发下载、拒绝申请、查看注册 Mac/配对 iPhone、撤销身份及查看审计。页面内确认显示重签发/撤销影响；模块真实 ID 只读，同名别名不会合并。
- 邀请状态有已消费身份的精确关联；撤销、备注、推送登记状态及旧记录元数据已具备后端能力，供 W04 页面使用。
- APNs 升级工具支持 schema 3 并保留 `--public-origin`；源码包加入管理程序、Web 资源、部署模板和指南。
